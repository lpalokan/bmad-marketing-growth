# Capture Why-Now

<instructions>
Distill the account's triggers and intent into a single, defensible why-now
statement that downstream scoring, storyline, and outreach can lead with.
Output is a short section appended to the account profile (or `v{n}.md`).
</instructions>

<process>
1. Read the account profile's triggers/intent section (or gather them first via
   capability BP). Read `signal-library.md` if present for the trigger taxonomy.
2. Rank the triggers by strength and recency. A why-now needs a real, recent,
   account-specific change — not a generic market trend. The strongest **confirmed
   pain candidates** come from: the growth curve (volume up + team flat = "keep
   pace"), a cost/offshoring mandate ("afford"), a live obligation with a clock, a
   named finding, or the leader's **own public words** about a pain (capability LP) —
   the last is the strongest lead-in material there is. Mirror their vocabulary.
3. Write the why-now as one or two sentences in the form:
   "**Why now:** <specific recent change at the account> → <why that creates a
   need our offering addresses>." Cite the trigger source.
4. If no genuine trigger exists, say so plainly ("No account-specific why-now
   found — timing is cold") rather than manufacturing urgency. Timing feeds
   Mira's separate timing score.
5. Note 1-2 secondary/emerging signals worth monitoring (track them via capability SS / the signal library).
6. Write into the profile / `v{n}.md`; update `state.yaml` if in the protocol.
</process>
